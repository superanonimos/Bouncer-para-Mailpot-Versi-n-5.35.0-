MailPoet Bouncer (Publikate)

Módulo técnico para el procesamiento desatendido y seguro de rebotes (Hard Bounces) para MailPoet 5.31+ mediante IMAP/Sockets, clasificación conservadora RFC 3464 y tareas periódicas en WP-CLI.

Descargar mailpoet-bouncer.zip Paquete final listo para subir e instalar directamente en WordPress (wp-content/plugins/)

Versión Plugin

1.2.0 (Hardening & Producción)

Compatibilidad PHP

PHP 8.1, 8.2, 8.3, 8.4

Transporte IMAP

ext-imap + Fallback Sockets

Requisito WordPress

WP 6.0+ / MailPoet 5.31+

Características Principales del Plugin

Diseñado para funcionar en VPS Linux (AlmaLinux 9 / CentOS Web Panel) con máximo aislamiento operacional:

Componente Mecanismo Estado
Conector IMAP Híbrido Usa ext-imap con UIDs; fallback automático a SocketImapClient (TLS/STARTTLS). Operativo
Clasificador RFC 3464 Enfoque conservador: solo códigos 5.1.X / 5.2.1 confirmados como hard bounce; 4.X.X y 5.2.2 son soft. Protección Activa
Actualizador de Suscriptores Arquitectura en 3 niveles: MailPoet Doctrine 5.x, MailPoet Models y fallback directo en $wpdb. Idempotente
Registro de Auditoría Tabla dedicada wp_pkmb_audit_log con purga automática tras 60 días. Sin Fuga de Datos
Ejecución sin Timeout Comando WP-CLI wp mailpoet-bouncer process con lock por transient para crontab de sistema. Aislado de HTTP
Ejecución Manual & Barber Pole Botón "Procesar ahora" en wp-admin con barra de barbería animada, secuencia de pasos y resumen. Operativo

Simulador de Diagnóstico RFC 3464

Pruebe cómo el algoritmo del clasificador analiza cabeceras de entrega y códigos de diagnóstico.

Automatización en Crontab de Servidor

Para evitar bloqueos de peticiones web y asegurar ejecución desatendida en AlmaLinux 9 / CWP: 

*/5 * * * * /usr/local/bin/wp mailpoet-bouncer process --path=/home/usuario/public_html > /dev/null 2>&1

Comandos disponibles:

Comando Propósito
wp mailpoet-bouncer process Ejecución ordinaria por lotes según configuración de Ajustes.
wp mailpoet-bouncer process --dry-run Modo simulación: parsea y audita sin modificar suscriptores en MailPoet.
wp mailpoet-bouncer process --limit=100 Sobrescribe el tamaño del lote (1 a 500 mensajes).
wp mailpoet-bouncer process --force Ignora el lock previo en caso de cierre abrupto del servidor.

Reglas de Seguridad y Criterios Aplicados

Regla de Seguridad Implementación Concreta
Prevención de Inyección SQL 100% de consultas usan $wpdb->prepare() o la API de $wpdb->insert() / $wpdb->update().
Sanitización y Escapado sanitize_email(), sanitize_text_field(), absint() y esc_html() en cada límite de entrada/salida.
Control de Acceso Verificación estricta de current_user_can('manage_options') y nonces criptográficos en endpoints AJAX.
Aislamiento de Errores Excepciones en mensajes individuales no cancelan el lote; se registran advertencias sin abortar.
Zero CDNs Externos Todos los scripts y estilos se sirven localmente sin dependencias en la nube no auditadas.
